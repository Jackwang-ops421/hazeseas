## Overview

Races matter because players often use race spins and rerolls early. The homepage should help users understand how to think about races without promising exact best choices or hidden values.

A race guide should not tell players to reroll endlessly just because a race is rare. Instead, it should explain whether a race supports the player's current build, combat style, and progression goal. If exact bonuses are not verified, do not publish them as fact.

### Race Decision Notes

#### Do not reroll blindly

Race spins are limited. Players should check what each race is useful for before spending rerolls.

#### Match race to build

A race is more valuable when it supports the way the player actually fights or farms.

#### Update after patches

Race value can shift after balance changes. If race data is uncertain, mark it as pending verification.

# 2、网站主题色与默认模式

## 结论

**默认选择暗色主题。**

Haze Seas 的官方视觉以深海、青蓝色技能特效、紫色雾气和高亮战斗效果为主。暗色背景更能突出游戏截图、Fruit 图标、Tier 标签和代码卡片，也更符合 Roblox 动作 RPG 玩家对资料站的视觉预期。

主色建议使用：

* **Ocean Cyan**：导航、高亮链接、选中状态
* **Deep Navy**：页面背景
* **Mist Violet**：Tier List、特殊标签的辅助色
* **Compass Gold**：主要 CTA，但不要大面积使用

```css
/* 导航页主题色 - 亮色主题 */
:root {
  --nav-theme: 190 78% 42%;        /* ocean cyan */
  --nav-theme-light: 190 82% 56%;  /* lighter cyan */
}

/* 导航页主题色 - 暗色主题 */
.dark {
  --nav-theme: 190 82% 56%;        /* luminous ocean cyan */
  --nav-theme-light: 190 92% 68%;  /* brighter cyan highlight */
}
```

推荐的基础背景配置：

```css
:root {
  --background: 210 30% 98%;
  --foreground: 218 35% 15%;
  --card: 0 0% 100%;
  --border: 210 20% 88%;
}

.dark {
  --background: 220 40% 7%;
  --foreground: 200 25% 94%;
  --card: 218 34% 11%;
  --border: 215 25% 21%;
}
```

主 CTA 可以单独使用金色：

```css
:root {
  --cta-accent: 43 96% 56%;
  --cta-accent-foreground: 220 40% 8%;
}
```

不建议把整站主色设成红色或纯紫色。红色更适合作为 Boss、Expired Code 或危险提示；紫色更适合作为 Mythical、Awakening、特殊 Fruit 标签。

# 3、多语言

## 结论：首发语言优先级

1. **English — `en`**
2. **Brazilian Portuguese — `pt-BR`**
3. **Spanish — `es`**
4. **Russian — `ru`**

品牌名 **Haze Seas** 和旧名称 **Haze Piece** 都应保持英文原名，不要音译。只本地化 `Wiki`、`Codes`、`Fruits`、`Guides` 等描述词。

| 优先级 | 语言                 | 本地化主题名                                     | 建议目录         | 旧名称表达                 |
| --: | ------------------ | ------------------------------------------ | ------------ | --------------------- |
|   1 | English            | `Haze Seas Wiki — Codes, Fruits & Guides`  | `/` 或 `/en/` | `formerly Haze Piece` |
|   2 | Portuguese, Brazil | `Haze Seas Wiki — Códigos, Frutas e Guias` | `/pt-br/`    | `antigo Haze Piece`   |
|   3 | Spanish            | `Haze Seas Wiki — Códigos, Frutas y Guías` | `/es/`       | `antes Haze Piece`    |
|   4 | Russian            | `Haze Seas Wiki — коды, фрукты и гайды`    | `/ru/`       | `ранее Haze Piece`    |

## 排序依据

### 1. English

绝大部分核心高搜索量词均为英语，例如：

* `haze seas codes`
* `haze seas trello`
* `haze seas tier list`
* `haze seas wiki`
* `haze seas fruit tier list`
* `haze seas discord`
* `haze seas fruits`

英语必须作为首发内容和数据更新的源语言。

### 2. Brazilian Portuguese

葡语查询虽然单个词量不如英语，但覆盖面很广，已经出现：

* `haze seas livro haki`
* `haze seas itens`
* `haze seas livro de equipamento 4`
* `haze seas acessorios`
* `codigos de haze seas`
* `oque vale uma dragon no haze piece`
* `codigos de haze piece`

这说明葡语用户不仅搜索 codes，还搜索 Haki、装备书、配饰、物品和交易价值，适合建立完整本地化栏目，而不是只翻译兑换码页。

### 3. Spanish

西语相关样本包括：

* `haze piece como conseguir la espada ace`
* `codigos haze piece`
* `codigos de haze piece`
* `codes de haze seas`

西语用户目前仍大量使用旧名称 Haze Piece，因此西语页面 Title 和首段必须同时包含 `Haze Seas` 与 `antes Haze Piece`。

### 4. Russian

俄语当前存在 `коды в haze seas`，Google Trends 样本中的 `коды на haze piece` 还出现了快速增长信号。俄罗斯用户应优先获得 Codes、Tier List、Fruits 和 Beginner Guide 四类页面。 

### 暂不首发法语的原因

样本中 `haze seas combien de seas` 有较明显需求，但目前法语关键词主要集中在一个问题，Codes、Fruits、Haki、Bosses 等主题的词群宽度不如葡语、西语和俄语。法语可以作为第 5 阶段候选，而不应挤占首批四种语言的更新资源。

## 多语言技术实现

建议使用下面的 `hreflang`：

```html
<link rel="alternate" hreflang="en" href="https://hazeseashub.wiki/" />
<link rel="alternate" hreflang="pt-BR" href="https://hazeseashub.wiki/pt-br/" />
<link rel="alternate" hreflang="es" href="https://hazeseashub.wiki/es/" />
<link rel="alternate" hreflang="ru" href="https://hazeseashub.wiki/ru/" />
<link rel="alternate" hreflang="x-default" href="https://hazeseashub.wiki/" />
```

每种语言都应使用独立 URL、独立 Title、独立 Meta Description 和自引用 canonical。不要通过浏览器语言自动强制跳转，否则可能影响 Google 抓取和用户手动切换语言。
